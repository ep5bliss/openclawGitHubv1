# PART 6: AI CLONE SETUP (Step-by-Step)

## One-Time Setup (Do This Weekend)

### Step 1: Record Your Consent Video (HeyGen)
- Find a clean background (blank wall, good lighting)
- Record yourself reading a provided consent script (HeyGen provides it)
- Takes 5 minutes
- HeyGen processes it in 24–48 hours
- You now have a digital twin forever

### Step 2: Clone Your Voice (ElevenLabs)
- Record 5–10 minutes of yourself speaking naturally
- Upload to ElevenLabs
- It clones your voice tone, pace, and inflection
- Use this voice in HeyGen for maximum realism

### Step 3: Build Your Script Templates
Save these prompts in a Google Doc called "AI SCRIPTS":

**Hook-Only Prompt:**
```
Give me 10 TikTok hooks for [PRODUCT]. 
Each hook must be under 7 words. 
Start with a pattern interrupt — question, bold claim, or shocking stat.
```

**Full Script Prompt:**
```
Write a 30-second TikTok Shop affiliate script for [PRODUCT].
Structure: Hook (3 sec) → Problem (5 sec) → Solution/Demo (15 sec) → Social proof (5 sec) → CTA (2 sec).
Conversational tone. No corporate language.
```

### Step 4: Your Daily Clone Workflow
```
Morning (10 min):
1. Open Claude → paste script prompt → get script
2. Open HeyGen → paste script → select your avatar → click Generate
3. Go to gym. Video renders while you work out.

Afternoon (10 min):
4. Download rendered clone video
5. Open CapCut → add captions (1 click) → add trending sound
6. Schedule via TikTok Creator Studio
```

**You filmed 0 minutes. You have a new video posting tonight.**

# PART 7: TIKTOK SHOP AFFILIATE SYSTEM

## How to Find Winning Products (Daily 20-Minute Process)

1. **Open TikTok Shop Affiliate Center** → Browse → Sort by "Commission Rate" + "GMV"
2. **Check Kalodata** → Filter: last 7 days, $10k+ revenue, 10%+ commission
3. **Criteria for a winner:**
   - Commission 10%+
   - Price point $20–$80 (impulse buy range)
   - Solves a visible problem
   - Can be demonstrated in 30 seconds
   - Has at least 100 reviews (social proof exists)
4. Add to your product pipeline doc (Google Sheet: Product | Commission | Angle | Status)

## Your Posting Strategy
- **4–5 posts per day** is the TikTok algorithm sweet spot for growth
- **Split:** 2–3 real videos + 1–2 AI clone videos
- **Best times:** 7am, 12pm, 5pm, 8pm (test and adjust with your analytics)
- **1 video = 1 product = 1 angle.** Don't cram multiple products.

## UGC Pitching System (Do 3 per day)

**Find brands:** TikTok Creator Marketplace, #TikTokMadeMeBuyIt, brands you already use

**Pitch template (copy this):**
```
Hi [Brand Name] team,

I'm a UGC creator specializing in [niche] content for TikTok Shop. 
I create authentic, conversion-focused videos (not influencer content — 
raw UGC that brands use in their own ads).

I'd love to create 3 test videos for [Product Name]. 
My rate is $[150–300] per video, delivered in 5 business days.

Happy to share my portfolio. Would this be a fit?

[Your name]
```
