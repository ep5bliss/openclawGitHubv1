### Typography System

**Font 1: League Spartan Bold** (or Anton as alternative)
- Use for: Main section titles, cover text, hero headlines
- Example: "MATCH JOURNAL", "GROUP A", "CHAMPION"
- Weight: Bold (700–900)
- Transform: ALL CAPS always

**Font 2: Montserrat SemiBold/Regular**
- Use for: Body text, field labels, instructions, table data
- Example: "Fill in your predictions below", column headers
- Weight: SemiBold (600) for labels, Regular (400) for body
- Transform: Sentence case or ALL CAPS for labels

**Font 3: Bebas Neue**
- Use for: Numbers, scores, statistics, countdown digits
- Example: Score displays, player numbers, point totals
- Weight: Regular (400) — Bebas Neue is display weight by default
- Transform: Always ALL CAPS

## CANVA SETUP INSTRUCTIONS

### Step 1: Start Your Design
1. Open Canva.com
2. Click "Create a design"
3. Choose "Custom size"
4. Enter: 8.5 × 11 inches (or 2550 × 3300px for 300dpi print)
5. Click "Create New Design"

### Step 2: Set Up Brand Colors
1. Go to any element → click color
2. Click the "+" next to "Document colors"
3. Add each hex code from the palette above
4. Repeat for all 8 brand colors

### Step 3: Install Fonts
All fonts are free via Google Fonts (available in Canva):
- League Spartan → Search "League Spartan" in Canva font picker
- Montserrat → Search "Montserrat"
- Bebas Neue → Search "Bebas Neue"

### Step 4: Create Master Template
Build one page as a template with:
- Navy background rectangle (full bleed)
- Header zone with brand colors
- Content zone guidelines
- Footer strip in gold
Then duplicate for each new page.

## GRAPHIC STYLE GUIDE

### DO USE these Canva element searches:
- "soccer ball outline minimal" — for icon accents
- "geometric hexagon" — for soccer ball texture pattern
- "stadium silhouette" — for background graphics
- "trophy outline minimal" — for award pages
- "star badge flat" — for rating elements
- "soccer field top view minimal" — for team builder page
- "lightning bolt icon" — for excitement ratings
- "checklist clipboard minimal" — for planner sections
- "flag minimal" — for country indicators
- "goal net minimal outline" — for score sections

### DO NOT USE:
- Any element with specific team colors or logos
- Any recognizable player artwork
- Cartoon or comic style elements
- Busy patterned backgrounds
- Watermarked stock elements

### Photo Usage:
- If using photos: Use abstract crowd shots, stadium atmospheres, soccer balls only
- All photos must be from Canva's licensed library
- No specific player or team identification
- Prefer illustrations over photography for main designs

### Icons:
- Use outline/line style consistently (not filled)
- Recolor all icons to brand colors
- Standard icon size: 24px for inline, 48px for featured
- Never mix filled and outline styles on the same page

## LAYOUT GRID SYSTEM

### Standard Page Grid:
- Margins: 0.5 in all sides
- Content width: 7.5 in
- Gutter (between columns): 0.25 in
- Header height: 1–2 in
- Footer height: 0.25–0.5 in
- Column system: 12-column grid

### Spacing System:
- Extra Small: 4px (between label and input)
- Small: 8px (between elements within a section)
- Medium: 16px (between sections on same page)
- Large: 32px (between major content blocks)
- XL: 64px (between section titles and content)

## PRINT SPECIFICATIONS

### Standard Version (Home Printing):
- Size: 8.5 × 11 in
- Resolution: 300 DPI
- Color mode: CMYK
- Bleed: 0.125 in if print shop, none for home
- File format: PDF (Print)

### A4 Version (International):
- Size: 210 × 297mm
- All margins adjusted proportionally
- Resolution: 300 DPI

### Digital/Screen Version:
- Size: 1920 × 1080px (landscape) or 1080 × 1350px (portrait)
- Resolution: 72–96 DPI
- Color mode: RGB
- File format: PDF or PNG

### Canva Download Settings:
When exporting from Canva:
- File type: PDF Print
- Color profile: CMYK (if available on your plan)
- "Crop marks and bleed": ON (if sending to print shop)
- Compression: Do not compress (max quality)

## MOBILE VERSION ADAPTATIONS

For phone-optimized versions:
- Size: 1080 × 1920px (9:16 portrait)
- Increase all font sizes by 20–30%
- Simplify multi-column layouts to single column
- Make all input fields larger (minimum 60px height on screen)
- Use larger touch-friendly checkboxes
- Test readability at 5 inches screen width

---

## SPANISH VERSION ADAPTATIONS

Key translation considerations:
- Spanish text runs ~20% longer — reduce font sizes slightly or abbreviate labels
- Section titles translate:
  - MATCH JOURNAL → DIARIO DEL PARTIDO
  - GROUP TRACKER → SEGUIMIENTO DE GRUPO
  - CHAMPION → CAMPEÓN
  - WATCH PARTY → NOCHE DE PARTIDO
  - FAMILY CONTEST → CONCURSO FAMILIAR
  - FAN BINGO → BINGO DEL FANÁTICO
- Keep design identical — swap text only
- Spanish version: Separate Canva template with translated text layers
- Pricing: Same price point — list as "English + Spanish" for higher perceived value
